# Motor City Online — Community Preservation Efforts

**Archived:** 2026-05-11

## Post-Shutdown History

After official servers shut down on **August 29, 2003**, the game became unplayable. Over the following two decades, several community-driven efforts emerged to preserve and restore access to the game.

---

## Offline Launcher

A community-created patch that enables single-player racing against AI opponents. This is the primary way to play MCO today.

- **Availability:** Included with My Abandonware release, also distributed via GTRCars.net
- **Mode:** Set launcher to Mode 16 for AI races
- **Status:** Working on Windows 7 through 11 with DirectPlay enabled

---

## MCO Re-Fired

A fan project attempting to revive the multiplayer component of Motor City Online. The project developed a custom launcher with a menu imitating the original game UI, plus a **Car Builder** tool for customising vehicles.

- **Forum:** http://www.mcorefired.com/Forum/index.php
- **Discord:** Community Discord server exists (exact invite unavailable)
- **Status:** No public news for a long time; multiplayer revival did not succeed
- **Legacy:** Mods for new cars and tracks released by the team

### Community Resources
- **Facebook group:** "Motor City Online" (active community sharing memories and files)
- **Reddit:** r/MotorCityGameMemories (dedicated subreddit for former players)
- **Steam Workshop:** MCO car packs created for other racing games (e.g., various packs with 30+ cars, Washington state license plates)

## Modern Compatibility

MCO runs on modern Windows with some configuration:

| Issue | Solution |
|-------|----------|
| DirectX 8 requirement | Enable DirectPlay (Windows 8+) |
| Resolution locked to 640x480 | Edit `3DSetup.ini` to show all resolutions |
| Widescreen unsupported | Use dgVoodoo2 wrapper |
| High framerate / fast cars | Enable VSync or cap to 30 FPS |
| Installation fails on modern Windows | Run `Setup.exe` in Windows XP compatibility mode |

See `15-myabandonware-preservation-guide/` for full installation steps.
