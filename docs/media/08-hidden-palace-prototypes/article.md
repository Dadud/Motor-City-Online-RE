## Jun 27, 2001 Prototype (Public Beta 1)

- **Build Date:** June 27, 2001
- **Build Name:** Public Beta 1
- **Dump Status:** Released, redump needed
- **File Dump Date:** April 12, 2026
- **Origin:** CD-R

### Notes
- First beta disk released to the public by EA
- Different installation icon compared to final
- Contains a **Stunt Track** and a **Derby Oval Track** not present in the final game
- Still references EA Racing site when attempting to connect
- Unplayable by normal means; content can be moved to final release and launched using Debug exe / -Nofront command
