# Motor City Online System Requirements

**Compiled from:** GameSpot Review (Nov 2001), IGN Review (Nov 2001), Computer Gaming World Issue 212 (Mar 2002), PCGamingWiki, and retail packaging  
**Last Updated:** 2026

---

## Official Minimum Requirements

| Component | Specification |
|-----------|---------------|
| **OS** | Windows 95 / 98 / ME / 2000 / XP |
| **CPU** | Pentium II 350 MHz |
| **RAM** | 64 MB |
| **HDD** | 600 MB free space |
| **Internet** | Internet connection (dial-up supported) |
| **DirectX** | DirectX 8.0 or higher |

## Official Recommended Requirements

| Component | Specification |
|-----------|---------------|
| **CPU** | Pentium III 500 MHz |
| **RAM** | 128 MB |
| **Internet** | Broadband (high-bandwidth) connection |
| **GPU** | 16 MB Direct3D-compatible video card |

## Contemporary Hardware Context

When Motor City Online launched in October 2001, these requirements reflected the mid-range PC market:

- **Pentium II 350 MHz** was entry-level; the Pentium III 500 MHz recommendation was modest even for 2001
- **64 MB RAM** was standard for Windows 98-era gaming, though 128 MB was quickly becoming the norm
- **Dial-up support** was explicitly mentioned, though reviewers noted broadband was "strongly recommended" due to lag issues
- The **600 MB install** was relatively small compared to contemporary titles

## Reviewer Hardware Tests

### IGN (Dan Adams, Nov 2001)
- **Test Rig 1:** Athlon Thunderbird 1.4 GHz, 512 MB RAM, GeForce3 — graphics "not that pretty"
- **Test Rig 2:** Pentium III 600 MHz, 256 MB RAM, GeForce2 — "a little slowdown"

### Computer Gaming World (George Jones, Mar 2002)
- **Test Rig:** 2.0 GHz machine, T3 Internet connection — "frame rates and lag are abysmal"

### GameSpot (Stephen Poole, Nov 2001)
- Noted that the game ran on a range of hardware but latency issues were independent of local machine specs
- Observed that opponents on dial-up (especially AOL dial-up) caused significant sync problems regardless of the reviewer's connection speed

## Modern Preservation Notes

For players attempting to run Motor City Online on modern systems (via the Offline Launcher or other preservation methods), the following compatibility considerations apply:

### Operating System
- The game was designed for Windows 9x/2000/XP era
- Modern Windows (10/11) requires compatibility mode adjustments
- dgVoodoo2 wrapper recommended for Direct3D rendering on modern GPUs

### Network
- Original game required an active internet connection to EA servers
- Server shutdown (August 29, 2003) made the retail client non-functional
- The **Offline Launcher** (community-developed) bypasses server requirements
- DirectPlay must be enabled in Windows Features for network functionality

### Display
- Original resolution: 800x600 or 1024x768
- Modern widescreen displays may require dgVoodoo2 for proper aspect ratio
- Windowed mode possible through configuration files

### Input
- Full force-feedback steering wheel support (Logitech MOMO Force, Microsoft Sidewinder Force Feedback Pro confirmed)
- Keyboard, joystick, and gamepad supported
- The game was "designed with a wheel in mind" (CNN/GamePro review)
